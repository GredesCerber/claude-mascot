# Галерея README

PNG в этой папке экспортируются штатным рендером Claude Mascot.
Это увеличенные пиксельные кадры приложения, а не снимки всего рабочего стола.
Чужие окна, пользовательские настройки и содержимое экрана для экспорта не нужны.

Из корня репозитория:

```powershell
cargo run --manifest-path rust/Cargo.toml --example readme_gallery -- docs/images
```

На Windows GNU можно добавить `+stable-x86_64-pc-windows-gnu` после `cargo`.
Восемь петов на общей картинке показывают реальные позы и палитру.
Башня из четырёх петов фиксируется только после её успешной сборки в симуляции
с `SocialCoordinator` и `ContactCoordinator`; при неудаче экспорт завершается ошибкой.
Масштабирование целочисленное, без сглаживания пикселей.
