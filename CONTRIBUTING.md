# Разработка

Основная Windows-версия находится в `rust/`; рабочая ветка `main`.
Изменения присылай отдельным pull request. Для ошибки укажи версию, Windows,
масштаб экрана, количество петов, FPS и шаги воспроизведения. Личные пути,
содержимое папок и чужие окна в отчёт добавлять не нужно.

Перед PR выполни из `rust/`:

```powershell
cargo fmt --all -- --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
```

Инструкции для MSVC и GNU: [rust/README.md](rust/README.md).
Сохраняй единый пиксельный стиль Claude, независимость физики от FPS,
приоритет действий пользователя и ограниченную частоту фоновых реакций.
Изменения поведения проверяй воспроизводимыми симуляциями.

## Выпуск

1. Увеличить версию Cargo.toml/Cargo.lock и добавить `rust/docs/releases/<версия>.md`.
2. Дождаться зелёного CI точного коммита в `main`.
3. Создать и отправить тег `rust-v<версия>` на этот коммит.
4. Release workflow проверит исходники, соберёт EXE, MSI, ZIP и SHA256SUMS,
   загрузит черновик, проверит digest assets и опубликует релиз.
5. Проверить скачивание и обнаружение версии старым portable EXE.

Не перезаписывать опубликованные теги и файлы. Исправления выпускаются новой
версией. MSI-файлами управляет Windows Installer; portable helper их не заменяет.
