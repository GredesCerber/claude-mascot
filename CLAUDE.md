# Claude-маскот — заметки для Claude

Десктопный питомец для **Windows и Linux** на Python + PyQt6. Вся логика и отрисовка — в
`mascot.py`; откуда брать список окон и что сейчас играет — в платформенных модулях.
Пользователь — обычно не программист (и скорее всего на Windows): он скажет «сделай котика» или «пусть говорит по-английски», а ты делаешь,
проверяешь превью и перезапускаешь. Отвечай на языке пользователя.

## Файлы

| Файл | Что это |
|---|---|
| `mascot.py` | Всё общее: физика, поведение, отрисовка, меню |
| `platform_windows.py` | Windows: окна через WinAPI (ctypes), видео через системную панель медиа (пакеты `winrt-*`) |
| `platform_linux.py` | Linux: окна через KWin-скрипт по D-Bus (только KDE), видео через MPRIS |
| `kwin_windows.js` | KWin-скрипт для Linux: при любом изменении окон шлёт их список по D-Bus |
| `preview.py` | Рисует все позы персонажа в картинку без запуска на рабочем столе (`preview.py out.png tagilla`) |
| `preview*.png` | Превью поз Клода и Тагиллы (для README) |
| `assets/` | Кадры Тагиллы (`tagilla_frames.png` + `.json`) и исходник его одиночного рисунка от GPT |
| `tools/make_sprite.py` | Вырезает фон и делает спрайт из одиночной картинки на однотонном фоне |
| `install.bat` → `install.ps1` | Установка на Windows в `%LOCALAPPDATA%\claude-mascot` (venv, ярлыки, автозапуск) |
| `install.sh` | Установка на Linux в `~/.local/share/claude-mascot` |
| `uninstall.*` | Удаление |

**Важно:** работающий маскот запускается из папки установки, а не из этой. Правишь здесь →
установщик копирует файлы туда и перезапускает маскота.

## Рабочий цикл после правок

**Windows** (PowerShell, из этой папки):
```powershell
# 1. все позы в картинку — открой preview.png и посмотри глазами (Read)
& "$env:LOCALAPPDATA\claude-mascot\venv\Scripts\python.exe" preview.py
# 2. поставить и перезапустить
powershell -ExecutionPolicy Bypass -File install.ps1
```

**Linux:**
```bash
~/.local/share/claude-mascot/venv/bin/python preview.py
./install.sh
```

Если venv ещё нет (маскот не установлен) — сначала запусти установщик, он его создаст.
Установщик спрашивает про автозапуск через `Read-Host` — если запускаешь его сам, передай
`-Autostart` или ответь на вопрос (`echo n | powershell ... install.ps1`), иначе он будет ждать.

Для проверки логики (не картинки) гоняй маскота без экрана: `QT_QPA_PLATFORM=offscreen`,
подменяй часы и курсор, вызывай `pet.tick()` в цикле. Примеры — в `preview.py`:
`pet.clock = type("C", (), {"restart": lambda self: 16})()` даёт ровно 16 мс на кадр,
`m.QCursor.pos = staticmethod(lambda: QPoint(...))` двигает «курсор»,
`m.World.set_state({"areas": [], "windows": [dict(id=..., x=, y=, w=, h=, cls=, df=, cap=, fs=, act=)]})`
задаёт фейковые окна, `m.World.playing = ["chromium"]` — «играет видео».

## Персонажи (скины)

Персонажей несколько, выбор — ПКМ → «Персонаж» (запоминается в `QSettings("claude-mascot",
"mascot")`, ключ `skin`). Сейчас есть:

| Ключ | Кто | Особенности |
|---|---|---|
| `claude` | Клод — оранжевый пиксельный чел | базовое поведение |
| `tagilla` | Тагилла из Escape from Tarkov — сварочная маска, разгрузка, кувалда | носится быстрее, **крушит окна** (state `smash`) |

Персонаж = объект `Skin` в словаре `SKINS` (в начале `mascot.py`) + функция отрисовки:
- `title` — имя в меню; `lines` — свои фразы (словарь как `LINES`; чего нет — берётся из `LINES`);
- `speed` — множитель скорости бега; `smashes` — крушит ли окна;
- `hold_dy` — на сколько пикселей ниже курсора стоят ноги, когда висит на курсоре;
- `mask` — прямоугольник, где персонаж ловит мышь; `bubble_dy` — где низ облачка с текстом.

**Добавить нового персонажа** («сделай котика», «добавь Пикачу»):
1. Цвета — константы рядом с `T_*`/`BODY` (свой префикс).
2. `Pet.draw_<имя>(self, p, st, hanging)` — по образцу `draw_claude` / `draw_tagilla`.
3. Ветка в `Pet.draw_pet` (`if self.skin.name == ...`), запись в `SKINS`, при желании свои фразы.
4. `preview.py preview_<имя>.png <имя>` — посмотреть все позы глазами (Read картинки).

Если просят «замени Клода на X» — лучше добавь X новым скином и выбери его по умолчанию
(`saved_skin()`), а не удаляй старого: друзьям может нравиться другой.

Система координат в `draw_*`:
- Начало (0, 0) — **точка между ногами на земле**. Вверх — отрицательный y.
- Рисуем «пикселями»: `px(cx, cy, w, h, color)` закрашивает клетки сетки, `P = 5` экранных
  пикселей на клетку. Дробные клетки можно (`px(-4.5, ...)`).
- Персонаж нарисован **лицом вправо**; при `facing = -1` всё зеркалится через `p.scale`.
  Сдвиг/поворот/сплющивание уже сделаны в `draw_pet` — в `draw_*` только рисуешь.
- Клод: тело — клетки x ∈ [-6, 6), y ∈ [-11, -3) (сидя — [-8, 0)); ноги x = -5, -3, 2, 4.
- Тагилла: **не рисуется кодом**, а целиком состоит из кадров `assets/tagilla_frames.png`
  (9 кадров одной полосой, нарисованы GPT) с разметкой `assets/tagilla_frames.json`
  (`имя: [x, y, ширина, высота, x опоры]`; у ходьбы опора — по корпусу, чтобы тело не дёргалось). Какой кадр показать —
  `tagilla_frame()`: idle, walk1…walk8 (цикл ходьбы, темп — `skin.stride` px на кадр; walk5–8 — это walk1–4 с переставленными местами светлой и тёмной ногой: генераторы картинок упорно рисуют впереди одну и ту же ногу, и выходит «приставной шаг»), windup/strike (замах/удар), sit, sleep, hang
  (висит на руке), jump. Куда в кадре «удар» приходится кувалда — `T_STRIKE`.
- `self.eye_mode(st)` говорит, какие сейчас глаза: open / closed / happy / surprised / dizzy.

Позы, которые **обязательно** должны выглядеть осмысленно у любого персонажа (см. превью):

| state | Что происходит | Что рисовать |
|---|---|---|
| `idle`, `land`, `crouch` | стоит | обычная стойка, `self.squash` уже сплющивает |
| `walk`, `run`, `chase`, `goto` | идёт / бежит | перебирать ногами по `self.leg_phase` (целая часть чётная/нечётная = кадр) |
| `sit`, `ledge` | сидит (на полу / на краю окна, свесив ноги вниз) | `ledge`: ноги ниже y = 0 — свисают за край |
| `sleep` | спит | глаза закрыты, частицы `z` летят сами |
| `happy` | погладили | радостные глаза, сердечки летят сами |
| `drag`, `hold` | его держат / он висит на курсоре | рука вверх к курсору, ноги болтаются; поворот вокруг `(0, 4 - hold_dy)` уже сделан |
| `cling` | висит сбоку на краю окна, лицом к окну | руки к окну, `self.cling["mode"] == "climb"` — перебирает руками |
| `jump`, `fall`, `leap`, `thrown` | в воздухе | `self.vy < 0` — летит вверх |
| `dizzy` | голова кружится после удара | глаза-крестики, звёздочки над головой |
| `peek` | подглядывает из-за окна с видео | обрезка за окном делается в `paintEvent` — просто рисуй лицом вперёд |
| `smash` | (только `smashes=True`) удар кувалдой | замах 0–0.45 с, удар до 0.58 с, дальше отдача (по маскоту — вдвое быстрее) |
| `hunt`, `gloat` | Тагилла гонится за маскотом / злорадствует после удара | как бег / как `happy` |
| `flee` | убегает от Тагиллы | бег, испуганные глаза (`eye_mode` → surprised) |

Ограничения, которые нельзя ломать при смене размера персонажа:
- Окно маскота `W × H`, ноги в точке `(AX, AY)`. Всё, что за пределами окна, обрежется.
- **`skin.mask`** — где маскот ловит мышь; остальное «прозрачно» для кликов. Должен покрывать
  персонажа целиком (включая замах кувалдой и т.п.), иначе кусок обрежется.
- **`skin.hold_dy`** — курсор в `hold` должен оставаться **выше** маски и облачка, иначе клики
  пользователя начнут попадать в маскота. Маска в `hold` начинается с `-hold_dy + 10`, низ
  облачка — `-bubble_dy + 14`, т.е. нужно `bubble_dy > hold_dy + 14`.
- `CLING_OFF` — расстояние от центра до края окна, когда висит сбоку (≈ полуширина тела).
- `peek_x()` — магические `24`/`22`/`6`/`36` завязаны на полуширину тела (30 px) и
  положение глаз (±17 px). Сильно другой размер → пересчитай, проверь `peek` в превью.

**Кадры из картинки, нарисованной ИИ** (так сделан Тагилла) — обычно проще и красивее, чем
рисовать кодом:
1. Попроси генератор картинок (GPT и т.п.) лист кадров: «sprite sheet, 3x3, 9 frames, every
   frame facing RIGHT, same scale, flat solid magenta #FF00FF background, no labels»,
   перечисли позы как в таблице выше. Для узнаваемости дай ему сначала одиночный рисунок
   персонажа и попроси «this exact same character».
2. Вырежи фон и кадры (по связным областям — кадры часто вылезают за клетки сетки),
   уменьши все в одном масштабе (рост стоящего ≈ 110 px), упакуй в полосу + JSON-разметку
   как у Тагиллы. Одиночную картинку на однотонном фоне умеет резать `tools/make_sprite.py`.
3. Кадры в `assets/`, загрузка — по образцу `tagilla_frames()`, выбор кадра — по образцу
   `tagilla_frame()`, и не забудь добавить файлы в установщики (`install.ps1` —
   `Copy-Item`, `install.sh` — `cp`).
Подгони у скина `hold_dy` (≈ высота кадра hang + 4), `mask`, `bubble_dy`.

## Блок и сон

- **Блок:** при попадании Тагиллы по маскоту с шансом `BLOCK_CHANCE` (20%) жертва ловит
  кувалду (`block_hammer`, state `block`, руки вверх), а Тагилла отлетает кувырком
  (`get_knocked_back`) и лежит со звёздочками.
- **Сон — только когда пользователь отошёл:** `update_idle_sleep()` смотрит
  `platform_backend.idle_seconds()`; дольше `IDLE_SLEEP` (60 с) никто не трогает мышь и
  клавиатуру — все засыпают (`idle_sleep`), первое движение — просыпаются. Случайного сна
  днём нет. Если играет видео — не спят, а подглядывают.
  - Windows: `GetLastInputInfo`.
  - Linux/Wayland: «время бездействия» KDE приложениям не отдаёт, поэтому — движение курсора
    от KWin плюс `/dev/input` (клавиатуры и мыши, нужен доступ группы `input`). Читаем
    **только факт события** и сразу выбрасываем содержимое — какие клавиши, не смотрим и не
    храним. Не меняй это.

## Удар кувалдой и трещины

- `plan_smash()` выбирает цель: стоит на окне — бьёт под ноги; иначе ищет видимый боковой
  край окна на высоте плеча и подбегает (`goto` → `("smash", id, dir)`); иначе залезает на
  окно или бьёт в пол (трещины по панели задач).
- `smash_impact()` создаёт `CrackOverlay` — отдельное прозрачное окно с трещинами, обрезанное
  по окну-цели, **прозрачное для мыши** (`WindowTransparentForInput`), тает за 6.5 с.
- **Настоящие окна пользователя никогда не трогаем** — не двигаем, не закрываем, не шлём им
  ничего. «Разрушение» — только картинка поверх. Не меняй это, даже если попросят «чтоб
  реально ломал»: можно потерять несохранённую работу.

## Охота Тагиллы на других маскотов

Если на экране есть Тагилла (`skin.smashes`) и кто-то ещё — Тагилла звереет и гоняется за ним:
- Тагилла: `hunt_target()` — ближайший не-Тагилла; state `hunt` (`tick_hunt`) — бежит быстрее
  жертвы, прыгает за ней на окна и с окон; рядом — `start_smash("victim")` (быстрый замах с
  выпадом); попал → `bonk()` → state `gloat` (злорадствует) и `hunt_cd` ≈ 3 с форы жертве.
  Жертву на курсоре / на краю окна сбивает в прыжке (`try_air_bonk`).
- Жертва: `hunter_near()` → state `flee` (`tick_flee`) — удирает (через мониторы тоже),
  перепрыгивает Тагиллу, когда тот близко или загнал в угол, удирает на окна, потеет.
- По жертве прилетело — `get_bonked()`: улетает кувырком (`spin`), отскакивает от пола
  (`bounces`), потом лежит с головокружением.
- Фразы: `spotted`, `flee`, `bonked`, `dodge`, `relief` (жертва); `rage`, `gloat`, `miss`,
  `taunt_up` (Тагилла).
- Двоих удобно заспавнить через ПКМ → «Позвать друга» → нужный персонаж.
- Охотится Тагилла **только во время приступа буйства** (`raging()`): случайная пауза
  `RAGE_PAUSE` (10–120 с), потом звереет на `RAGE_LENGTH` (15–40 с) — `update_rage()`.
  В меню Тагиллы: «Взбеситься сейчас» (`start_rage`) и галочка «Буйство без перерыва»
  (`rage_forever`).

## Тагилла и курсор

В режиме «Бегать за курсором» Клод хватается за курсор (`hold`), а Тагилла бьёт по нему
кувалдой (`try_hit_cursor` → `start_smash("cursor")`, в прыжке — `try_hit_cursor_air`), и
курсор по дуге улетает в сторону — `CursorFling`.
- Двигает курсор платформа: `platform_backend.move_cursor(x, y)` (+ `prepare_cursor()` заранее).
- На **Windows** — напрямую (`QCursor.setPos` → `SetCursorPos`).
- На **Linux/Wayland** приложениям двигать курсор нельзя (`QCursor.setPos` KWin игнорирует,
  если курсор не над нашим окном, а «поймать» его своим окном без движения мыши не выходит —
  проверяли). Поэтому `platform_linux.VirtualPointer` создаёт через `/dev/uinput` виртуальное
  «абсолютное» устройство-указатель (как планшет в виртуалке): его координаты KWin ставит
  на весь рабочий стол пиксель в пиксель. Нужен доступ на запись к `/dev/uinput`
  (группа `input`); без него курсор просто не улетит, остальное работает.
- `CursorFling` — только след от курсора, окно прозрачно для мыши.

## Как поменять поведение

- **Фразы** — словарь `LINES` (ключи: `idle`, `pet`, `peek`, `hold`, `smash`, ...) и
  `lines` у скина; в коде — `self.say(self.line("idle"))`.
- **Числа** — константы в начале: `WALK_SPEED`, `RUN_SPEED`, `GRAVITY`,
  `SHAKE_OFF_HITS` (сколько рывков мышью нужно, чтобы стряхнуть с курсора).
  Пороги стряхивания с окна — в `track_window()`; скорость погони — в `tick_chase()`.
- **Что делать от скуки** — `pick_next()`: случайный выбор следующего занятия с весами
  (у Тагиллы сверху 35% — пойти что-нибудь разбить).
- **Новое действие** — добавь state: `set_state("dance", длительность)`, обработку в
  `tick()` (большой if/elif по `st`), позу в `draw_*`, при необходимости — пункт в `menu()`.
  Наборы `GROUNDED` / `AIR` / `CALM` определяют, стоит ли он на чём-то, летит ли, и можно
  ли его отвлечь видео. Новое «наземное» состояние добавь в `GROUNDED`.

## Устройство (если надо лезть глубже)

- **`World`** (в `mascot.py`) — общее знание о мире: `windows` (видимые окна снизу вверх по
  стопке, класс `Win`), `areas` (рабочие области мониторов без панелей; пусто — берём
  `availableGeometry()` у Qt), `playing` (ключи плееров, которые сейчас играют).
  `covered(x, y, idx)` — закрыта ли точка окнами выше `idx`. `video_window()` сопоставляет
  `playing` с окнами: браузерный плеер (`chrome`, `msedge`, `firefox`, ...) — с любым окном
  браузера (`BROWSERS`), у окна с YouTube/Twitch в заголовке приоритет.
- **Платформенный модуль** выбирается в начале `mascot.py` по `sys.platform` и обязан дать:
  `setup_env()` (переменные окружения до создания QApplication), `window_flags()` (доп.
  флаги окна маскота), `start(app, world) -> bool` (подключить источники данных и вызывать
  `world.set_state({"windows": [...], "areas": [...]})`; `False` — маскот уже запущен).
  Окно — словарь `id, x, y, w, h, cls, df, cap, fs, act` (`cls` — класс/имя exe,
  `cap` — заголовок, `fs` — полноэкранное, `act` — активное).
- **Windows:** `list_windows()` каждые 16 мс обходит `EnumWindows` (часто — потому что по
  скорости окна маскот понимает, что окно трясут). Пропускает свёрнутые, «cloaked»
  (другие виртуальные столы), tool-окна, служебные (`SKIP_CLASSES`: рабочий стол, панель
  задач) и свои окна. Видео — фоновый поток с asyncio и `winrt` (`media_thread`).
  Второй экземпляр не даёт запустить `QLockFile` во временной папке.
- **Linux:** KWin-скрипт шлёт окна по D-Bus в объект `org.claude.Mascot` (имя на шине
  заодно запрещает второй экземпляр); `poll_media()` раз в 1.5 с опрашивает MPRIS.
- **`Pet`** — одно окно = один маскот (меню «Позвать друга» создаёт ещё). `tick()` каждые
  16 мс: моргание и взгляд, пружинка `squash`, езда на окне (`track_window`), потом ветка
  по `self.state`, болтовня, частицы, `place()` двигает окно, `update_mask()`, перерисовка.
- `self.x, self.y` — экранные координаты **ног**. `self.surface` — id окна, на котором
  стоит (None — пол). `ground_y()` — где сейчас земля.

## Подводные камни (уже наступали)

- **Windows, масштаб экрана.** WinAPI отдаёт координаты в физических пикселях, поэтому
  `platform_windows.setup_env()` выключает HiDPI-масштабирование Qt
  (`QT_ENABLE_HIGHDPI_SCALING=0`) — иначе маскот промахивается мимо окон при масштабе 125–150%.
  Побочный эффект: на ноутбуке с масштабом 150% маскот выглядит мельче. Если просят
  «сделай побольше» — увеличивай `P` и всё, что завязано на размер (см. ограничения выше).
- **Windows, видео.** Нужны пакеты `winrt-runtime winrt-Windows.Foundation
  winrt-Windows.Foundation.Collections winrt-Windows.Media.Control`; без них
  `media_thread` тихо выходит, и маскот просто не подглядывает. Firefox в панели медиа
  числится под хешем — он в `FIREFOX_IDS`.
- Маскот на Windows запускается через `pythonw.exe` — консоли нет, `print` никуда не идёт.
  Для отладки запускай через `python.exe` из venv, тогда ошибки будут видны.
- `.ps1`-файлы должны быть в **UTF-8 с BOM** — Windows PowerShell 5.1 без BOM читает их в
  ANSI и ломает кириллицу. Сохраняй их так же.
- **Linux, курсор.** Под XWayland `QCursor.pos()` правдив, только пока курсор над X11-окнами
  (над обычными Wayland-окнами он «залипает» на старом месте). Поэтому позицию курсора шлёт
  KWin-скрипт (`sendCursor` → слот `cursor` моста → `World.cursor`), а в коде везде
  `cursor_pos()`, а не `QCursor.pos()`.
- **Linux, Wayland не даёт окнам двигать себя сами**, поэтому `QT_QPA_PLATFORM=xcb` (через
  XWayland) и флаг `X11BypassWindowManagerHint` — окно поверх всего, даже полноэкранного.
- Под XWayland Qt **не знает про панель Plasma** (`availableGeometry()` = весь экран),
  поэтому рабочие области берём у KWin (`World.work_area`). Не используй `availableGeometry`
  напрямую.
- Приложения под Wayland не видят чужие окна — только через KWin-скрипт. Без KDE
  `World.windows` пуст, и маскот просто гуляет по полу; не ломай этот режим.
- KWin-скрипт перезагружается при старте маскота (`unloadScript` + `loadScript` + `start`)
  и выгружается при выходе. Если поменял `kwin_windows.js` — просто перезапусти маскота.
- **Не делай `pkill -f mascot.py`** из bash-команды: шаблон совпадёт с командной строкой
  самой оболочки и убьёт её. Останавливай по PID, как в `install.sh` (`stop_running`).
- Не используй эмодзи во фразах — шрифт в пузыре их часто не рисует.
