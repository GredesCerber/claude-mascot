# Claude-маскот — заметки для Claude

Десктопный питомец для **Windows и Linux** на Python + PyQt6. Вся логика и отрисовка — в
`mascot.py`; откуда брать список окон и что сейчас играет — в платформенных модулях.
Пользователь — обычно не программист (и скорее всего на Windows): он скажет «сделай котика» или «пусть говорит по-английски», а ты делаешь,
проверяешь превью и перезапускаешь. Отвечай на языке пользователя.

## Файлы

| Файл | Что это |
|---|---|
| `mascot.py` | Всё общее: физика, поведение, отрисовка, меню |
| `platform_windows.py` | Windows: окна через WinAPI (ctypes), видео через системную панель медиа (пакеты `winrt-*`) |
| `platform_linux.py` | Linux: окна через KWin-скрипт по D-Bus (только KDE), видео через MPRIS |
| `kwin_windows.js` | KWin-скрипт для Linux: при любом изменении окон шлёт их список по D-Bus |
| `preview.py` | Рисует все позы в `preview.png` без запуска на рабочем столе |
| `install.bat` → `install.ps1` | Установка на Windows в `%LOCALAPPDATA%\claude-mascot` (venv, ярлыки, автозапуск) |
| `install.sh` | Установка на Linux в `~/.local/share/claude-mascot` |
| `uninstall.*` | Удаление |

**Важно:** работающий маскот запускается из папки установки, а не из этой. Правишь здесь →
установщик копирует файлы туда и перезапускает маскота.

## Рабочий цикл после правок

**Windows** (PowerShell, из этой папки):
```powershell
# 1. все позы в картинку — открой preview.png и посмотри глазами (Read)
& "$env:LOCALAPPDATA\claude-mascot\venv\Scripts\python.exe" preview.py
# 2. поставить и перезапустить
powershell -ExecutionPolicy Bypass -File install.ps1
```

**Linux:**
```bash
~/.local/share/claude-mascot/venv/bin/python preview.py
./install.sh
```

Если venv ещё нет (маскот не установлен) — сначала запусти установщик, он его создаст.
Установщик спрашивает про автозапуск через `Read-Host` — если запускаешь его сам, передай
`-Autostart` или ответь на вопрос (`echo n | powershell ... install.ps1`), иначе он будет ждать.

Для проверки логики (не картинки) гоняй маскота без экрана: `QT_QPA_PLATFORM=offscreen`,
подменяй часы и курсор, вызывай `pet.tick()` в цикле. Примеры — в `preview.py`:
`pet.clock = type("C", (), {"restart": lambda self: 16})()` даёт ровно 16 мс на кадр,
`m.QCursor.pos = staticmethod(lambda: QPoint(...))` двигает «курсор»,
`m.World.set_state({"areas": [], "windows": [dict(id=..., x=, y=, w=, h=, cls=, df=, cap=, fs=, act=)]})`
задаёт фейковые окна, `m.World.playing = ["chromium"]` — «играет видео».

## Как поменять внешность (сменить маскота)

Вся внешность — в `Pet.draw_pet()` (+ `draw_particles`, `draw_bubble`, `star`). Логика и
физика от внешности не зависят, поэтому новый персонаж — это переписать `draw_pet`.

Система координат в `draw_pet`:
- Начало (0, 0) — **точка между ногами на земле**. Вверх — отрицательный y.
- Рисуем «пикселями»: `px(cx, cy, w, h, color)` закрашивает клетки сетки, `P = 5` экранных
  пикселей на клетку. Дробные клетки можно (`px(-4.5, ...)`).
- Персонаж нарисован **лицом вправо**; при `facing = -1` всё зеркалится через `p.scale`.
- Текущий Клод: тело — клетки x ∈ [-6, 6), y ∈ [-11, -3) (сидя — [-8, 0)); ноги — столбики
  x = -5, -3, 2, 4 под телом; ручки — 2×2 по бокам тела (x = -8 и 6); глаза — x = -4 и 3.
- Цвета — константы `BODY`, `SHADE`, `LIGHT`, `EYE`, `BLUSH` в начале файла.

`draw_pet` смотрит на `self.state` и рисует позу. Позы, которые **обязательно** должны
выглядеть осмысленно у нового персонажа (см. `preview.png`):

| state | Что происходит | Что рисовать |
|---|---|---|
| `idle`, `land`, `crouch` | стоит | обычная стойка, `self.squash` уже сплющивает |
| `walk`, `run`, `chase`, `goto` | идёт / бежит | перебирать ногами по `self.leg_phase` (целая часть чётная/нечётная = кадр) |
| `sit`, `ledge` | сидит (на полу / на краю окна, свесив ноги вниз) | `ledge`: ноги ниже y = 0 — свисают за край |
| `sleep` | спит | глаза закрыты, частицы `z` летят сами |
| `happy` | погладили | радостные глаза, сердечки летят сами |
| `drag`, `hold` | его держат за макушку / он висит на курсоре | руки вверх, ноги болтаются; поворот вокруг (0, -60) уже сделан |
| `cling` | висит сбоку на краю окна, лицом к окну | руки к окну, `self.cling["mode"] == "climb"` — перебирает руками |
| `jump`, `fall`, `leap`, `thrown` | в воздухе | `self.vy < 0` — летит вверх |
| `dizzy` | голова кружится после удара | глаза-крестики, звёздочки (уже есть) |
| `peek` | подглядывает из-за окна с видео | обрезка за окном делается в `paintEvent` — просто рисуй лицом вперёд |

Ограничения, которые нельзя ломать при смене размера персонажа:
- Окно маскота `W × H`, ноги в точке `(AX, AY)`. Всё, что за пределами окна, обрежется.
- **Маска окна** (`update_mask`) задаёт, где маскот ловит мышь; остальное «прозрачно» для
  кликов. Прямоугольник `QRect(AX - 60, AY - 95, 120, 118)` должен покрывать персонажа.
  Если сделаешь его больше/меньше — поправь маску.
- `HOLD_DY` — насколько ниже курсора висят ноги в `hold`. Курсор должен оставаться **выше
  маски** (иначе клики пользователя начнут попадать в маскота). Верх тела ≈ `-HOLD_DY + 9`.
- `CLING_OFF` — расстояние от центра до края окна, когда висит сбоку (≈ полуширина тела).
- `peek_x()` — магические `24`/`22`/`6`/`36` завязаны на полуширину тела (30 px) и
  положение глаз (±17 px). Новый размер → пересчитай, проверь `peek` в превью.
- Пузырь с текстом рисуется над головой на `AY - 92` — для высокого персонажа подними.

Вместо рисования кодом можно использовать PNG-спрайты: загрузить `QPixmap` из файлов рядом
с `mascot.py` и в `draw_pet` выбирать кадр по `state` и `leg_phase`
(`p.drawPixmap(QRectF(-w/2, -h, w, h), pixmap)` — ноги в нуле). Файлы тогда добавь в
`install.sh` в строку `cp`.

## Как поменять поведение

- **Фразы** — списки `*_LINES` в начале файла (`IDLE_LINES` — просто так, `PET_LINES` —
  погладили, `PEEK_LINES` — подглядывает, `HOLD_LINES` — висит на курсоре и т.д.).
- **Числа** — константы в начале: `WALK_SPEED`, `RUN_SPEED`, `GRAVITY`,
  `SHAKE_OFF_HITS` (сколько рывков мышью нужно, чтобы стряхнуть с курсора).
  Пороги стряхивания с окна — в `track_window()`; скорость погони — в `tick_chase()`
  (`min(abs(gap) * 3.0, 700.0)`).
- **Что делать от скуки** — `pick_next()`: случайный выбор следующего занятия с весами.
- **Новое действие** — добавь state: `set_state("dance", длительность)`, обработку в
  `tick()` (большой if/elif по `st`), позу в `draw_pet`, при необходимости — пункт в `menu()`.
  Наборы `GROUNDED` / `AIR` / `CALM` определяют, стоит ли он на чём-то, летит ли, и можно
  ли его отвлечь видео. Новое «наземное» состояние добавь в `GROUNDED`.

## Устройство (если надо лезть глубже)

- **`World`** (в `mascot.py`) — общее знание о мире: `windows` (видимые окна снизу вверх по
  стопке, класс `Win`), `areas` (рабочие области мониторов без панелей; пусто — берём
  `availableGeometry()` у Qt), `playing` (ключи плееров, которые сейчас играют).
  `covered(x, y, idx)` — закрыта ли точка окнами выше `idx`. `video_window()` сопоставляет
  `playing` с окнами: браузерный плеер (`chrome`, `msedge`, `firefox`, ...) — с любым окном
  браузера (`BROWSERS`), у окна с YouTube/Twitch в заголовке приоритет.
- **Платформенный модуль** выбирается в начале `mascot.py` по `sys.platform` и обязан дать:
  `setup_env()` (переменные окружения до создания QApplication), `window_flags()` (доп.
  флаги окна маскота), `start(app, world) -> bool` (подключить источники данных и вызывать
  `world.set_state({"windows": [...], "areas": [...]})`; `False` — маскот уже запущен).
  Окно — словарь `id, x, y, w, h, cls, df, cap, fs, act` (`cls` — класс/имя exe,
  `cap` — заголовок, `fs` — полноэкранное, `act` — активное).
- **Windows:** `list_windows()` каждые 16 мс обходит `EnumWindows` (часто — потому что по
  скорости окна маскот понимает, что окно трясут). Пропускает свёрнутые, «cloaked»
  (другие виртуальные столы), tool-окна, служебные (`SKIP_CLASSES`: рабочий стол, панель
  задач) и свои окна. Видео — фоновый поток с asyncio и `winrt` (`media_thread`).
  Второй экземпляр не даёт запустить `QLockFile` во временной папке.
- **Linux:** KWin-скрипт шлёт окна по D-Bus в объект `org.claude.Mascot` (имя на шине
  заодно запрещает второй экземпляр); `poll_media()` раз в 1.5 с опрашивает MPRIS.
- **`Pet`** — одно окно = один маскот (меню «Позвать друга» создаёт ещё). `tick()` каждые
  16 мс: моргание и взгляд, пружинка `squash`, езда на окне (`track_window`), потом ветка
  по `self.state`, болтовня, частицы, `place()` двигает окно, `update_mask()`, перерисовка.
- `self.x, self.y` — экранные координаты **ног**. `self.surface` — id окна, на котором
  стоит (None — пол). `ground_y()` — где сейчас земля.

## Подводные камни (уже наступали)

- **Windows, масштаб экрана.** WinAPI отдаёт координаты в физических пикселях, поэтому
  `platform_windows.setup_env()` выключает HiDPI-масштабирование Qt
  (`QT_ENABLE_HIGHDPI_SCALING=0`) — иначе маскот промахивается мимо окон при масштабе 125–150%.
  Побочный эффект: на ноутбуке с масштабом 150% маскот выглядит мельче. Если просят
  «сделай побольше» — увеличивай `P` и всё, что завязано на размер (см. ограничения выше).
- **Windows, видео.** Нужны пакеты `winrt-runtime winrt-Windows.Foundation
  winrt-Windows.Foundation.Collections winrt-Windows.Media.Control`; без них
  `media_thread` тихо выходит, и маскот просто не подглядывает. Firefox в панели медиа
  числится под хешем — он в `FIREFOX_IDS`.
- Маскот на Windows запускается через `pythonw.exe` — консоли нет, `print` никуда не идёт.
  Для отладки запускай через `python.exe` из venv, тогда ошибки будут видны.
- `.ps1`-файлы должны быть в **UTF-8 с BOM** — Windows PowerShell 5.1 без BOM читает их в
  ANSI и ломает кириллицу. Сохраняй их так же.
- **Linux, Wayland не даёт окнам двигать себя сами**, поэтому `QT_QPA_PLATFORM=xcb` (через
  XWayland) и флаг `X11BypassWindowManagerHint` — окно поверх всего, даже полноэкранного.
- Под XWayland Qt **не знает про панель Plasma** (`availableGeometry()` = весь экран),
  поэтому рабочие области берём у KWin (`World.work_area`). Не используй `availableGeometry`
  напрямую.
- Приложения под Wayland не видят чужие окна — только через KWin-скрипт. Без KDE
  `World.windows` пуст, и маскот просто гуляет по полу; не ломай этот режим.
- KWin-скрипт перезагружается при старте маскота (`unloadScript` + `loadScript` + `start`)
  и выгружается при выходе. Если поменял `kwin_windows.js` — просто перезапусти маскота.
- **Не делай `pkill -f mascot.py`** из bash-команды: шаблон совпадёт с командной строкой
  самой оболочки и убьёт её. Останавливай по PID, как в `install.sh` (`stop_running`).
- Не используй эмодзи во фразах — шрифт в пузыре их часто не рисует.
