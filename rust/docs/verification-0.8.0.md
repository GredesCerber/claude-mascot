# Проверка 0.8.0

9 ноября 2026. Windows GNU Rust 1.99.1; последующая сборка GitHub использует
Windows MSVC со статическим CRT.

## Подтверждено локально

- 194 теста прошли: 90 library, 3 binary, 101 integration.
- Форматирование и Clippy all-targets с `-D warnings` прошли.
- 23 проверки планирования/исполнения: достижимость, точки посадки, стабильные
  ID и перекрытия; фактическое приземление; подход/карабканье/перебирание
  на верх без скачков координат при scale 0,75/1/1,5; спуск на пол;
  закрытие/перенос окна, изменение масштаба и настроек, ручная отмена,
  ограничение времени маршрута. Подготовка действительно удерживает позу
  до 0,22 секунды, после чего движение использует обычную физику.
- Отдельный интеграционный прогон четырёх seed по 600 секунд через обычный
  `Pet::update`: наблюдались разные цели, подход, присед, карабканье и
  самостоятельный спуск; позиции оставались конечными и в рабочей области.
- Тесты MSI/portable выбирают разные способы обновления: MSI открывает
  проверенный URL релиза, portable выбирает скачивание EXE; неверные адреса
  и теги отклоняются. Защита MSI-файлов от EXE helper сохранена.

## Выпуск и проверки артефактов

Tag workflow повторяет тесты/Clippy, собирает EXE, MSI и ZIP, валидирует MSI
и сверяет digest загруженных assets до публикации. Результат запуска доступен
в Actions. После публикации проверяются скачанные контрольные суммы и
совпадение EXE в ZIP/MSI, CLI-обнаружение релиза и проверка версии из
MSI-каталога с marker-файлом без UI-заглушки.

## Практические пределы

Новые маршруты проверены преимущественно детерминированной симуляцией.
Полный ручной прогон реальных окон, смешанных DPI и нескольких устройств
не выполнен. Установку/обновление/удаление MSI на отдельной VM не прогоняли.
Автоматического запуска нового MSI нет. Добровольный спуск целится на пол;
планирования цепочек через несколько нижних окон пока нет.

Исходные root install/uninstall скрипты не входят в эту Rust-доработку.
