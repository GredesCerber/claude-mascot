# Доработка Claude Mascot командой Terra

Начато 12 ноября 2026, база 0.12.6 (`d7ef790`).
Интегратор: основной агент. Изменения разрабатываются в отдельных worktree.

| Направление | Исполнитель / ветка | Состояние | Условие готовности |
| --- | --- | --- | --- |
| Пять петов и общая физика | terra_behavior / terra/behavior-polish | Интегрировано, проверки прошли | Совместные сценарии с коллизиями, окнами, башнями и чехардой проходят |
| Понятные отказы | terra_behavior / terra/behavior-polish | Интегрировано, проверки прошли | Причины отказа корректны, коротки и не повторяются каждый кадр |
| Частоты и пресеты | terra_settings / terra/settings-company | Интегрировано, проверки прошли | Каждый регулятор влияет на свою автокатегорию; ручные команды доступны |
| Управление компанией | terra_settings / terra/settings-company | Интегрировано, проверки прошли | Добавление, удаление, возврат на экран, цвета и состав сохраняются |
| Приглашения и общение | terra_behavior / terra/behavior-polish | Интегрировано, проверки прошли | Игры учитывают занятость, завершение и отдых; физика не подменена телепортами |
| Внутренние опоры | terra_perches / terra/ui-perches | Интегрировано, проверки прошли | UIA-геометрия отделена от окон; рабочая посадка и потеря опоры; opt-in |

Контракты: Frequencies{wandering,social,exploration,cursor,speech}: 0..100,
50 сохраняет прежнюю частоту; 0 выключает только автоматическую категорию.
SocialCoordinator.frequency управляет социальными автозапусками.
UiPerchMonitor::new/set_enabled/snapshot(&World) -> Vec<UiSurface>.

Интегрированы коммиты: 6142269, 536114a, c82817e, ae89e76, c35877c,
f70c373, cbadc7d, b6509a3, 8f98c32. Дополнительно исправлены пересечения
контролов, сброс истории при переносе компании и обратная связь ручных отказов.

Проверка перед выпуском: коммит и handoff каждого агента, проверка diff,
фокусные тесты, общий cargo test, fmt и Clippy. Публикация и установка
только после интеграционных проверок. Root install/uninstall scripts не входят в работу.
