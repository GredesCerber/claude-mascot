# Новый интерфейс настроек

Статус: нативное меню из семи разделов реализовано; доводка UX — 0.12.0.
В нативном окне доступны общая пауза, область действия настроек, поиск занятий,
подсказки и клавиатурная навигация с прокруткой. HTML-макет остаётся отдельным
эскизом. Таблица ниже также содержит идеи будущих расширений, не обещания
реализованных возможностей: отдельного сохранённого состава, профилей поведения
и опор на внутренних элементах чужих приложений пока нет.

## Постоянные элементы окна

Сверху: миниатюра и выбор пета, область изменения «этот пет / все петы»,
пауза всех, возвращение потерявшихся петов на экран.
Слева: разделы, справа: короткая страница настроек. Разрешить изменение
размера окна; прокрутка только содержимого. Сохранить выбранный раздел.
Стиль: тёплый пузырь диалога Claude, спокойные контрасты, Segoe UI,
пиксельный персонаж в предпросмотре, читаемые обычные контролы.

## Разделы

| Раздел | Основные настройки | Дополнительные настройки |
| --- | --- | --- |
| Питомцы и вид | список, добавить/убрать, цвет, размер, шкала эмоций | имена, сохранённый состав и палитры каждого пета |
| Поведение | общий уровень активности, прогулки, реакции на курсор | частоты отдельных групп действий, длительности отдыха, поведенческие профили |
| Опоры | пол, окна, ярлыки; позднее элементы интерфейса | правила по приложениям, ручные полки, занятые места, исключения |
| Друзья | общение, игры, башни, потасовки | частоты игр, диапазон расстояний, ограничения узких опор |
| Реплики | показать/скрыть, частота | размер текста, длительность, тихий режим, отключение отдельных тем |
| Производительность | FPS, полноэкранный режим | собственное значение FPS, экономия энергии, диагностика пропусков кадров |
| Обновления | установленная версия, проверка, одно подтверждение | необязательная тихая установка, результат и журнал, автозапуск |

Общие параметры приложения: FPS, автозапуск, полноэкранная видимость,
обновления и диагностика. Выбор пета на них не влияет: явно писать это
над страницей и отключать переключатель области на общих страницах.
Внешний вид, частоты поведения и реплики проектируются с индивидуальным
значением и наследованием общего профиля. Сейчас в коде индивидуален
главным образом цвет; полноценное сохранение состава и индивидуальных
профилей потребует расширения модели настроек.

## Гибкость без перегрузки

Начальная страница показывает основные параметры. Частные частоты и
численные ограничения раскрываются в «Дополнительно». Общая интенсивность
масштабирует разрешённые действия, но не включает то, что пользователь выключил.
Группы «Прогулки», «Прыжки», «Карабканье», «Курсор», «Спокойные занятия»,
«Общение» получают отдельные частоты; это частота решений, не FPS анимации.
Случайный выбор безопасных маршрутов сохраняется.

Профили: Спокойный / Обычный / Непоседа / Свой. Применение профиля
меняет только поведение и заранее показывает состав изменений. Цвет, FPS,
обновления и исключения приложений не сбрасываются профилем поведения.

Каталог 75 занятий вынести из длинного выпадающего списка в поиск с
категориями, избранным и предпросмотром. «Запустить сейчас» отделить от
«Разрешать случайно»: просмотр занятия не меняет постоянную настройку.
В макете каталог ещё не реализован.

## Меню ПКМ

Оставить коротким: Погладить, Действие…, Позвать друга, Пауза,
Вернуть на экран, Настройки…, Выход. Проверку обновления можно оставить
рядом с версией в трее, а каталог и численные параметры перенести в окно.
ПКМ на конкретном пете открывает настройки этого пета; трей — общую страницу.
Исключить дублирование больших вложенных списков в нескольких местах.

## Изменение и восстановление настроек

Обычные параметры применяются сразу, с видимым подтверждением сохранения;
ошибка записи показывается как ошибка, а не как успешное сохранение.
Добавить «Отменить последнее изменение» и сброс только текущего раздела.
Сброс всех настроек и удаление состава требуют отдельного подтверждения.
Числа проверять совместно: min < max, допустимый FPS, предел количества петов.
Не сохранять пустой/невалидный ввод при каждом нажатии клавиши.

Предусмотреть импорт/экспорт с проверкой схемы, миграцией старого JSON и
предпросмотром изменений. Импорт настроек не запускает действия и не включает
тихую установку обновлений без явного выбора. Тихое обновление выключено
по умолчанию; обычный режим требует одно подтверждение.

## Состояния и доступность

Связанные параметры имеют понятные причины недоступности: нет второго пета,
отключено общение, приложение не предоставляет геометрию опор.
Не показывать будущий параметр работающим переключателем в установленном
приложении до реализации. В макете такие группы помечены «проект».
Цвет не является единственным индикатором состояния; все контролы имеют
подписи, фокус клавиатуры и порядок Tab. Проверить 100/150/200% DPI,
длинные русские подписи, минимальный размер окна и сохранение текста
редактируемого поля при фоновом обновлении состояния.

## Перенос в приложение

1. Разделить нативное окно на страницы, распределив существующие контролы;
   сохранить события и единый неблокирующий цикл приложения.
2. Упростить ПКМ, добавить быстрые команды и версию в раздел обновлений.
3. Ввести профили петов и сохранение состава с миграцией настроек.
4. Добавлять новые параметры только вместе с реализованным поведением:
   частоты, каталог, внутренние опоры и исключения приложений.

Приёмка: существующие настройки доступны и сохраняются; переключение
страницы не теряет ввод; общие параметры не выглядят индивидуальными;
сброс раздела не меняет остальные; FPS перетаскивания не ухудшается;
одно подтверждение MSI-обновления сохраняется.
