# Обновления Rust-версии

Пет проверяет стабильные GitHub Releases репозитория `GredesCerber/claude-mascot`
при запуске и затем примерно раз в шесть часов. Проверку можно запустить из
меню "Проверить обновления". Ветка, PR и локальная пересборка обновлением не
являются: версия опубликованного релиза должна быть выше установленной.

## MSI с версии 0.10.0

Пет сам скачивает `claude-mascot-<версия>-x64.msi`, проверяет размер и SHA-256
по обязательному digest GitHub. Также нужен проверенный digest EXE из того же
релиза. Имя файла, версия и адрес должны точно соответствовать репозиторию и
тегу. Произвольные команды и скрипты из метаданных не выполняются.

Перед установкой MSI открывается как база данных только для чтения. Проверяются
ProductName, UpgradeCode, ProductVersion, установка для текущего пользователя
и ожидаемая папка LocalAppData. Сам EXE в MSI-установке не заменяется вручную.

В отдельную папку подготовки копируется локальный helper. Он повторно проверяет
пакет и блокирует его изменение. Только после подтверждения готовности helper
пет завершает работу. Helper ждёт именно свой родительский процесс и запускает
системный Windows Installer с `/qn /norestart`. Перезагрузка Windows не
запрашивается. При занятом установщике выполняются ограниченные повторные попытки.
После успеха проверяется SHA-256 установленного EXE и пет перезапускается.

Если установка не удалась, восстановлением файлов управляет Windows Installer.
Helper может перезапустить только точный прежний EXE либо проверенный новый.
Результат доступен в "Настройки → Результат последнего обновления"; журнал
установщика остаётся в папке подготовки. Настройки и количество петов сохраняются.
Текущие позы и расположение петов при перезапуске не восстанавливаются.

При включённых "Автопроверка обновлений" и "Устанавливать MSI автоматически"
подтверждений не требуется. Загрузка идёт в фоне; установка откладывается,
пока пет удерживается мышью, открыто окно настроек или активно полноэкранное
приложение. Отключение автоматической установки отменяет ожидающую установку.
При отключённой автоматической установке найденное обновление устанавливается
одним подтверждением, без перехода на страницу GitHub.

Новые установки включают автоматическую установку по умолчанию. Старые файлы
настроек не меняют прежнее согласие автоматически: новый переключатель можно
включить в окне настроек или меню ПКМ. Код обновлятора не может появиться в
уже установленной 0.9.0: для перехода нужна одна установка 0.10.0 или новее.
После обновления пропускается только начальная проверка; периодические проверки
продолжаются, чтобы не возникал цикл немедленных повторов.

## Portable

Portable использует отдельный проверенный EXE и запрашивает согласие на его
скачивание и замену. Helper сохраняет прежний EXE и откатывает замену при
ошибке. MSI-маркер запрещает этот способ обновления для Windows Installer.
Сохранённая настройка автоматической установки MSI не включает тихую замену
portable EXE.

## Канал и публикация

С 0.7.1 старое значение `kerimovernes/claude-mascot` мигрирует на канал этого
форка; отключённая проверка и пользовательские репозитории сохраняются.
Для собственного форка задайте `MASCOT_UPDATE_REPO=владелец/репозиторий` при
компиляции. Workflow подставляет свой `github.repository`.

Тег `rust-v<версия Cargo>` запускает проверки Windows/Linux и сборку Windows x64.
Релиз содержит EXE, ZIP, MSI и SHA256SUMS. Перед публикацией проверяются digest
загруженных assets и пригодность созданного MSI для встроенного обновлятора.

Опции Windows Installer описаны в [документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/msi/standard-installer-command-line-options).
