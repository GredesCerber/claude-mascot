# Проверка 0.7.1

9 ноября 2026. Изменения относительно 0.7.0: собственный канал релизов,
миграция старого адреса обновлений, конечные автономные прогулки/пробежки.

- Локальный Rust GNU: полный набор 167 тестов; отдельно проверена новая
  последовательность движения, паузы и повторного выбора на восьми seed.
- Нулевая интенсивность во время прогулки останавливает следующие решения;
  ручное сидение и сон сохраняются.
- Миграция канала сохраняет FPS, цвет и отключение автопроверки; произвольный
  адрес другого форка сохраняется; настройки проходят повторное сохранение.
- Форматирование и Clippy all-targets с `-D warnings`.
- Проверен синтаксис PowerShell-блоков release workflow.

Публикация выполняется отдельным tag workflow: тесты MSVC, сборка EXE/MSI/ZIP,
валидация MSI и сравнение GitHub digest каждого файла с SHA256SUMS до перевода
черновика в публичный релиз. Результаты конкретного запуска доступны в Actions.

Ограничения 0.7.0 сохраняются: нет полного ручного приёма окна настроек,
отдельной VM для установки/обновления/удаления MSI и полного аппаратного
mixed-DPI прогона. MSI пока обновляется новым установочным пакетом вручную.
Опубликованный portable цикл с заменой работающего процесса отдельно ещё
не подтверждён; получение metadata/скачивание проверяются после публикации.

Отличия поведения исходного Python: [behavior-parity.md](behavior-parity.md).
