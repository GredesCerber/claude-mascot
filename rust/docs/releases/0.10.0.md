# Claude Mascot Rust 0.10.0

MSI теперь обновляется внутри пета: скачивание, проверка SHA-256, тихая установка
через Windows Installer и перезапуск с сохранением настроек и количества петов.
Переходить на GitHub и вручную запускать новый пакет больше не требуется.

В настройках появились переключатели автопроверки и автоматической установки.
Для новых установок оба включены. Пользователи прежних версий могут включить
автоматическую установку; без неё достаточно одного подтверждения.
Установка подождёт окончания перетаскивания, закрытия настроек и выхода из
полноэкранного приложения. Результат и ошибка доступны в меню настроек.

Обновлятор принимает только пакет ожидаемой версии и семейства продукта,
с установкой для текущего пользователя. После установки сверяется также EXE.
Отдельный helper подтверждает готовность до закрытия пета; при неудаче
восстановлением MSI управляет Windows Installer, после чего запускается
проверенный прежний EXE, если он доступен. Автоматической перезагрузки Windows нет.

Одно обновление до этой версии нужно установить обычным MSI: старый EXE ещё
не содержит нового механизма. Portable сохраняет обновление с подтверждением.
Все изменения поведения и случайный выбор маршрутов из 0.9.0 сохранены.
