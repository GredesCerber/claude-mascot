# Claude Mascot Rust 0.11.3

Самостоятельная погоня за мышкой стала редкой: движение рядом с петом
больше не гарантирует запуск через 0,7 секунды. Есть случайное решение,
начальная спокойная пауза 90–150 секунд и отдельный перерыв 3–6 минут
после начала игры. Это минимальные паузы, а не обещание запускать погоню
по расписанию: нужны подходящий курсор и свободный пет.

Игра длится до 3,5 секунды, прекращается при остановке курсора или поглаживании.
Ручная постоянная погоня не меняется. Нулевая интенсивность, ручные команды,
сон и другие занятые состояния не запускают случайную игру.
Самостоятельный бег останавливается у конца текущей опоры.
