# Claude Mascot Rust 0.12.6

Строка заголовка окна настроек стала тёмной, в тон меню Claude, со светлым
текстом. Сохраняются стандартные кнопки окна, перетаскивание и привязка окон
Windows. Цвета повторно применяются при смене системной темы; системная тема
и настройки других приложений не меняются. Включает исправленную чехарду 0.12.5.
