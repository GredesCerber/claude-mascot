# Claude Mascot Rust 0.11.1

Исправлена стандартная иконка Windows у окна настроек: теперь в заголовке,
панели задач и Alt+Tab используется встроенная иконка Claude. Малый и большой
значки загружаются с учётом DPI и освобождаются при закрытии окна.

У семи разделов навигации появились небольшие пиксельные пиктограммы.
Текстовые подписи сохранены; внешние шрифты и файлы для значков не нужны.
