# Claude Mascot Rust 0.13.1

- Клод освобождает внутреннюю опору, когда курсор попадает в её поле: спрыгивает в сторону со свободным местом на экране. Ручная команда «сидеть» и сон сохраняют приоритет.
- Пет не планирует прыжок и не приземляется на внутреннюю опору под курсором, в том числе если курсор появился во время полёта.
- Новый друг получает свободный цвет из палитры с учётом уже перекрашенных и удалённых участников. Цвета существующих петов не меняются.
- Сохранённые частоты поведения применяются сразу при создании пета.

Внутренние опоры остаются экспериментальными и выключены по умолчанию.
Поддерживаются доступные через UIA поля ввода и разделители активного окна;
проверка реальных приложений и смешанного DPI ещё требуется.
