# Claude Mascot Rust 0.10.3

Контрольный патч для проверки перехода с 0.10.2 через встроенный MSI-обновлятор.
Код поведения и установки не изменён относительно исправления 0.10.2.

По умолчанию пет предлагает найденное обновление. После одного подтверждения
он скачивает MSI, проверяет пакет, устанавливает и перезапускается. Открывать
GitHub и запускать MSI вручную не требуется. Настройки сохраняются.

Полностью тихая установка доступна отдельным переключателем, но по умолчанию
выключена. Ошибка пути Windows Installer 1619 из 0.10.0/0.10.1 исправлена.
С этих двух версий один раз нужен исправленный MSI. Неудавшаяся установка
оставляет прежнюю версию и записывает причину в результат обновления.
