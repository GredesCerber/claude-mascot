# Claude Mascot Rust 0.12.0

- Пауза и продолжение для всех питомцев доступны в шапке настроек.
- Подписи объясняют область действия: выбранный питомец или все. Выбор питомца отключён в общих разделах.
- Поиск занятий по названию и группе, счётчик результатов и понятное пустое состояние.
- Разделы помнят прокрутку; частично видимые элементы обрезаются корректно. Фокус с клавиатуры прокручивает поле в видимую область.
- Длинные подписи помещаются целиком; есть пояснения к FPS, интенсивности, расстояниям и установке обновлений.
- Без второго питомца совместные игры недоступны, с объяснением причины.
- Приветствие в ответ на несколько горизонтальных движений курсора рядом. Дрожание и одно движение не считаются жестом; повтор не чаще раза в 45 секунд. Сон, ручные занятия и отключённые реакции не прерываются.
- Убрано случайное махание из обычного поведения и реакций на папки: вместо него питомец осматривается. Ручная команда «Помахать» сохранена.
