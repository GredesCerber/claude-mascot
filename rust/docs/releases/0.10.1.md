# Claude Mascot Rust 0.10.1

В результате последнего обновления теперь показывается текущая установленная
версия. Поведение, анимации и механизм установки из 0.10.0 сохранены.

Этот патч также используется для живой проверки перехода с 0.10.0 через
автоматический MSI-обновлятор. При включённых автопроверке и автоматической
установке пет сам скачает, проверит и установит пакет, затем перезапустится.
Настройки и количество петов сохраняются; результат доступен в меню настроек.

Версия 0.9.0 и более старые MSI ещё не содержат нового установщика: один раз
нужен новый MSI. Новые установки включают автоматическую установку по умолчанию;
для прежних настроек её можно включить новым переключателем.
