# Claude Mascot Rust 0.14.0

- Все 75 исходных иллюстраций получили отдельные последовательности действий: подготовка, основное действие и завершение. Общие мигающие эффекты заменены работой с предметами.
- Три новых занятия по мотивам Codrops: махать флагом, топать с двумя выбросами конфетти, выполнить два повторения с гантелью.
- Общие тело, глаза, палитра и пиксельный такт 12Гц; предметы связаны с ладонями. Реплики остаются разнообразными.
- Раздельные задний и передний слои для чашки, очков, страниц и аксессуаров. Руки соединены с плечами, предметы не отрываются при остаточной деформации после броска.
- Мягкая покадровая реакция ладоней при приземлении. Физика и пользовательский FPS сохраняются отдельно от темпа поз.
- Каталог содержит 78 занятий. Существующие ID, имена, цвета, состав компании и настройки сохранены.

Это процедурные интерпретации картинок под общий стиль приложения, а не точное копирование исходных персонажей. Проверки и визуальное ревью перечислены в docs/planning/activity-animation-rollout.md.
