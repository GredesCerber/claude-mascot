# Claude Mascot Rust 0.14.1

- Вместо списка занятий в настройках появилась галерея всех 78 анимаций: живые карточки, названия, группы и длительность.
- Превью используют цвет выбранного питомца. Поиск работает по названию, группе и идентификатору сцены.
- Выбор карточки не меняет поведение питомца. Для запуска используйте кнопку, двойной клик или Enter; доступны стрелки, Home/End и Page Up/Down.
- Прокручивается каталог; отрисовываются только видимые карточки. Превью работают в пиксельном такте 12 Гц и останавливаются при закрытии настроек или переходе в другой раздел.
- Питомцы, их имена, цвета и остальные настройки сохраняются при обновлении MSI.

Этот выпуск добавляет галерею. Темп и позы существующих анимаций не изменены; найденные при ревью недочёты записаны отдельно в docs/animation-review-2026-11-20.md.
