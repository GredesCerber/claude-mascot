# Claude Mascot Rust 0.11.2

Пет отскакивает от верхней границы рабочей области при броске и прыжке.
При сильном броске есть сжатие и короткая реплика; вертикальная скорость
после удара уменьшается. Ранее ограничение действовало только во время кувырка.

Если над текущим монитором есть соседний и тело помещается в проход,
общая граница не считается потолком. Проверены отрицательные координаты,
разные масштабы, возврат на пол, прежние броски, прыжки и кувырки.
