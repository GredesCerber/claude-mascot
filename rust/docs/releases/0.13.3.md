# Claude Mascot Rust 0.13.3

- Новый крабик получает первое свободное имя «Клод №N». Нумерация не растёт после удаления друзей; существующие имена и цвета сохраняются.
- Автоматическая погоня стала короткой игрой: 1–3 забега с небольшими паузами, затем отдых. Между играми остаётся длительный перерыв, частота регулируется настройкой погони.
- Исправлено распознавание обычного движения мыши при высокой частоте физики. Первая возможность поиграть появляется раньше, но игра не запускается от каждого движения.
- При стряхивании пет летит по направлению последнего рывка курсора. Учитываются вертикальные и диагональные движения, а плавное встряхивание работает и на 240 Гц.
- Ручные команды, сон, отключённые реакции и нулевая частота погони сохраняют приоритет.
