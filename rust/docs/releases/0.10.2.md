# Claude Mascot Rust 0.10.2

Исправлена ошибка 1619 при передаче канонического пути `\\?\...` в Windows
Installer. Для системного установщика используются обычные пути Windows;
проверки SHA-256 и блокировка скачанного пакета сохранены.

По умолчанию новое MSI-обновление требует одного подтверждения. После него
пет сам скачивает и проверяет пакет, устанавливает и перезапускается.
Отдельный переключатель полностью тихой установки остаётся доступным.
Обычная проверка обновлений включена по умолчанию.

В 0.10.0 и 0.10.1 этот путь установки не работал: Windows Installer возвращал
1619, а прежняя версия запускалась снова. Для перехода на исправленный
обновлятор один раз установи новый MSI. Настройки сохраняются.
