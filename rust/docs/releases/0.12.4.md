# Claude Mascot Rust 0.12.4

Исправлено сохранение внешнего вида: цвет каждого питомца и состав компании
сохраняются по стабильным идентификаторам и восстанавливаются после перезапуска
или обновления. Старые настройки с одним общим цветом продолжают загружаться.
Во «Внешнем виде» появилась кнопка «Всем разные цвета»: каждому питомцу
назначается свой цвет из восьмицветной палитры, результат сразу сохраняется.
Ранее не сохранённые индивидуальные цвета восстановить из старого формата нельзя.
