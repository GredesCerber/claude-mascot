# Claude Mascot Rust 0.12.3

Появляющаяся нижняя панель задач работает как мягкий батут: стоящий на полу
питомец слегка подпрыгивает и опускается на неё. Последовательные кадры
подъёма панели не запускают прыжок заново. При скрытии панели питомец
естественно опускается на нижний край экрана. Учитываются основная и
дополнительные панели задач; скрытая полоска в несколько пикселей игнорируется.
Питомцы на окнах, в социальных играх, во сне и при перетаскивании не запускают
эту реакцию. Положение и настройки Windows не изменяются.
