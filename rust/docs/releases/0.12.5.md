# Claude Mascot Rust 0.12.5

Исправлена чехарда с настоящими коллизиями: пет сначала набирает высоту
над другом, затем начинает двигаться вперёд. Дуга учитывает размеры обоих
питомцев, физические границы тел, место для приземления и потолок.
Скорость не обрезается с потерей точки посадки: при большем расстоянии
подбирается более высокая дуга. Посадка дальше от друга предотвращает
столкновение на спуске. Проверены размеры 75%, 100%, 150%, смешанные
размеры, короткие и длинные дистанции, серии из 2 и 10 прыжков с
реальными коллизиями и координатором поведения.
