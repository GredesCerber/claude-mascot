# Claude Mascot Rust 0.13.0

- Отдельные частоты прогулок, игр, исследования, погони и реплик; пресеты «Спокойные», «Живые», «Хаос». Ручные команды сохраняются.
- Управление компанией в настройках: добавить, убрать выбранного, вернуть всех на экран, дать имена, сохранить/загрузить/удалить до восьми наборов с личными цветами.
- Социальные приглашения со сближением на общей опоре; причины отказа, отдых и короткая радость после игры. Проверка посадки чехарды учитывает посторонних петов.
- Интеграционные сценарии пяти петов на масштабах 75%, 100%, 150% с контактами, окнами, панелью задач, башнями и чехардой.
- Экспериментальные внутренние опоры (выключены по умолчанию): поля ввода и разделители активного окна, ограниченный фоновый сбор UIA-геометрии без чтения текста. Посадка, следование за небольшим перемещением, редкие безопасные прыжки с пола и падение при потере опоры.

Внутренние опоры зависят от доступности геометрии в приложении. Чатовые сообщения,
виртуализированные списки и произвольные панели не поддерживаются; реальная
работа разных UIA-провайдеров и смешанный DPI требуют дополнительной проверки.
