- Собственный канал обновлений; старое значение репозитория мигрирует при чтении настроек.

  общие игры, башни, чехарда, палитра и отдельное окно настроек.

## Установка и обновление

Portable: распакуй ZIP и запусти claude-mascot.exe. Новый portable EXE проверяет
этот репозиторий при запуске и затем раз в шесть часов; скачивание и перезапуск
происходят после согласия. SHA-256 проверяется по digest GitHub Release.

Со старой сборки нужно один раз перейти вручную: она ещё смотрит в репозиторий
исходного автора. Затем канал будет сохранён в настройках автоматически.

MSI: установи новый пакет после закрытия приложения. Удаление через Windows
или ярлык в меню «Пуск». MSI пока не устанавливает обновления автоматически.

Это независимая версия сообщества на основе проекта kerimovernes, не продукт
Anthropic. Контрольные суммы файлов приложены в SHA256SUMS. EXE и MSI не имеют
Authenticode-подписи. Полный сценарий установки/удаления MSI на отдельной VM и
обновление portable с заменой работающего процесса ещё не проверены.
