# Claude Mascot Rust 0.13.2

- Ползунок размера всей компании: 75–300%, шаг 5%, немедленный результат и сброс на 100%.
- Расширены границы масштаба рендера и физики: столкновения, прыжки, опоры и социальные сцены учитывают крупных петов.
- Вместо вложенного подменю параметров в ПКМ теперь один пункт «Открыть настройки…».
- Автозапуск Windows и скрытие в полноэкранном режиме доступны на странице «Производительность».
- Включены исправления 0.13.1: освобождение внутренних опор под курсором, свободные цвета новых друзей и применение сохранённых частот при создании.

Размер действует на всю компанию. Имена, цвета и остальные настройки сохраняются.
Внутренние опоры экспериментальные, выключены по умолчанию.
