# Claude Mascot Rust 0.9.0

- Сильные столкновения и броски вызывают кувырок, затухающие отскоки и короткое головокружение со звёздочками. После этого Клод встаёт ровно.
- Два довольных Клода иногда устраивают дружескую потасовку. Запустить её можно через "Друзья → Вместе с другом" или окно настроек.
- До приподнятого окна пет подходит, приседает, подпрыгивает к боковому краю, цепляется и карабкается на верх. Между допустимыми маршрутами сохраняется случайный выбор, включая прямые прыжки.
- Устранено зависание на закрытых другим окном значках после Alt+Tab. Пет падает с текущего места; команды сидеть и спать сохраняются до приземления.
- Ожидание на удобном расстоянии от друга больше не блокирует исследование окон.
- Добавлено 35 реплик для ударов, восстановления и потасовки. Поворот тела остаётся покадровым на 12 Гц, физика работает на 240 Гц, частота отображения настраивается.

Перед установкой закрой старую версию. Установи новый MSI поверх прежнего,
чтобы сохранить настройки. Portable можно заменить файлами из ZIP.
MSI проверяет наличие обновлений и открывает страницу релиза; его установка
обновляется через Windows Installer. Portable сохраняет отдельный механизм
скачивания и замены EXE после согласия.

Проверки включают симуляцию высокого рабочего стола с плавающим окном,
перекрытия значков, разные масштабы, восемь петов и отрисовку поворота.
Полный ручной прогон на нескольких мониторах с разным DPI и чистый цикл
установки/удаления на отдельной VM остаются отдельными проверками.
