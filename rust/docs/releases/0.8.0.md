# Claude Mascot Rust 0.8.0

Пет исследует рабочий стол разнообразнее:

- Выбирает разные достижимые окна и места посадки, вместо постоянной ближайшей точки.
- Подходит к краю высокого окна, цепляется, карабкается и перебирается на верх.
- Приседает перед исследовательским прыжком; поза чёткая, покадровая.
- Иногда подходит к краю окна и сам спрыгивает на пол.
- Маршруты отменяются при захвате, ручных командах и изменении опоры.

Исправлена проверка обновлений MSI: вместо постоянной заглушки теперь
выполняется проверка GitHub и показывается установленная версия. При наличии
новой версии можно открыть страницу её установщика. MSI пока не устанавливает
обновление автоматически; portable сохраняет скачивание и замену EXE после согласия.

Перед установкой закрой старую версию. Настройки и цвета сохраняются.
EXE, ZIP, MSI и SHA256SUMS приложены к релизу. Windows 10/11 x64;
Python и Rust runtime не требуются.

Подходы ограничены безопасной опорой и границами экрана. Спуск планируется
на пол; сложных цепочек через нижние окна пока нет. Проверки выполнены
в симуляции и сборках; полный ручной прогон на нескольких DPI/мониторах
и полный цикл установки/удаления MSI на отдельной VM остаются непроверенными.
