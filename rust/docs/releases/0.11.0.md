# Claude Mascot Rust 0.11.0

Нативное окно настроек разделено на семь страниц с постоянной навигацией:
внешний вид, поведение, опоры, друзья, производительность, занятия, обновления.
Выбор пета остаётся в шапке при прокрутке. Цвет применяется к выбранному пету;
остальные существующие настройки общие, что явно указано в окне.

Проверка обновлений и последний результат доступны прямо в окне настроек.
Переключение страниц сохраняет введённые значения. Закрытие окна оставляет
петов работающими. Параметры внутренних UI-опор пока не реализованы;
страница опор сообщает об этом и содержит работающий переключатель ярлыков.

Сохранены прежние поведение, физика и обновление MSI с одним подтверждением.
