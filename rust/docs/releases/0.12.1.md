# Claude Mascot Rust 0.12.1

- Два вида лазания: профиль у боковой кромки с обеими лапками у края; вид со спины при подъёме по поверхности окна.
- Свободные окна, доходящие до пола, получают дополнительные маршруты по поверхности. Выбор маршрута случайный, с проверкой перекрытия, границ экрана и безопасного выхода наверх. Плавающие окна сохраняют прыжок к боковому краю.
- Башни могут собираться из 2, 3, 4, 5 и большего числа свободных участников (до 8). Спокойно сидящие и осматривающиеся питомцы тоже могут присоединяться.
- Размер самостоятельной башни меняется случайным образом. Ручная команда по-прежнему приглашает всех доступных на той же опоре; проверка места над башней сохранена.

- Чехарда идёт серией из 2–10 прыжков: короткий присед, более высокий прыжок, смена ролей. У края опоры прыгающий может перескочить назад через друга; после серии игра заканчивается и действует обычная пауза.
