# Проверка 0.10.0

10 ноября 2026. Локально Windows GNU Rust 1.99.1.

- 225 тестов проходят. Дополнительная проверка настоящего опубликованного MSI
  0.9.0 запущена отдельно и прошла; неправильная ожидаемая версия отвергается.
- Проверены выбор MSI вместо EXE, обязательные digest обоих файлов, версия,
  канонический адрес, размер, дубликаты, чужой продукт и машинная область установки.
- Старые настройки не включают автоматическую установку без выбора пользователя;
  новые установки включают её по умолчанию. Переключатель сохраняется в JSON.
- Поведение, маршруты, Alt+Tab-опоры и пиксельная отрисовка проходят прежние регрессии.
- CI выпуска дополнительно проверяет собранный MSI через тот же read-only
  валидатор, которым пользуется обновлятор.

Автоматический цикл на опубликованной следующей версии и аварийное восстановление
на отдельной VM являются отдельными проверками. Результат живого прогона
записывается в артефакты выпуска; этот документ не заменяет его.
